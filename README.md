# disc — тестирование воспроизведения DISC-теста

Моделям дают задание **перенести функционал теста DISC** со страницы
школы менеджмента Stratoplan (ссылка + исходники виджета) в копию —
самодостаточное HTML-приложение без бэкенда и без отправки результатов
на почту. Модель сама извлекает из исходников данные (24 вопроса), алгоритм
подсчёта баллов и поведение интерфейса. Протокол чистой генерации: один
сырой user-запрос → один ответ (готовый HTML-файл), без system prompt,
инструментов и диалога.

Качество переноса сравниваем с эталоном, снятым с оригинала (вопросы
посимвольно, типы d/i/s/c, алгоритм, поток): машинные проверки (структура,
посимвольные данные, смоук с пересчётом баллов) + судейство по 4 осям 0–4
(data / logic / ux / impl). Эталон модели не показывается.

Конвенции и процесс — **[AGENTS.md](AGENTS.md)** (главный документ workspace).

## Структура

| Путь | Что лежит |
|---|---|
| `test-assignment/TASK.md` | задание, которое получает модель |
| `test-assignment/reference/source/` | снимок оригинала: `widget.html` + `disc_patched.js` (входят в промпт), `page.html`, `result-page.html` (для судей), `manifest.json` |
| `test-assignment/reference/` | эталон для сравнения (модели не показывается): `original.md` + `questions.json` (24 вопроса с типами) |
| `test-assignment/prompts/` | собранный промпт прогона (версионируется) |
| `test-assignment/rubrics/` | рубрика оценки (4 оси 0–4) и план машинных проверок |
| `models/<модель>/` | карточка `model.md` + прогоны `test-assignment/run-XX/` (`session.json`, `solution/index.html`) |
| `reports/` | кросс-модельные своды; `spend.csv` платных API (вне git) |

## Быстрый старт

```bash
cp .env.local.example .env.local   # вписать адрес сервера моделей
curl "$OLLAMA_BASE_URL/api/tags"   # проверить доступность моделей
# раннеры: test-assignment/runner.py (планируется)
```
