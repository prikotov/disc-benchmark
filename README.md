# disc — тестирование воспроизведения DISC-теста

Модели получают одно задание: **изучить описание готового теста DISC
(школа менеджмента Stratoplan) и воспроизвести его как самодостаточное
HTML-приложение** — без бэкенда, без отправки результатов на почту.

Протокол чистой генерации: один сырой user-запрос → один ответ (готовый
HTML-файл), без system prompt, инструментов и диалога. Эталон (24 вопроса
со служебными типами d/i/s/c, алгоритм подсчёта, особенности оригинала)
снят с оригинала и одинаков для всех моделей. Оценка: машинные проверки
(структура, посимвольные данные, смоук с пересчётом баллов) + судейство
по 4 осям 0–4.

Конвенции и процесс — **[AGENTS.md](AGENTS.md)** (главный документ workspace).

## Структура

| Путь | Что лежит |
|---|---|
| `test-assignment/TASK.md` | задание, которое получает модель |
| `test-assignment/reference/` | эталон: описание оригинала + `questions.json` (24 вопроса с типами) |
| `test-assignment/prompts/` | собранный промпт прогона (версионируется) |
| `test-assignment/rubrics/` | рубрика оценки (4 оси 0–4) и план машинных проверок |
| `models/<модель>/` | карточка `model.md` + прогоны `test-assignment/run-XX/` (`session.json`, `solution/index.html`) |
| `reports/` | кросс-модельные своды; `spend.csv` платных API (вне git) |

## Быстрый старт

```bash
cp .env.local.example .env.local   # вписать адрес сервера моделей
curl "$OLLAMA_BASE_URL/api/tags"   # проверить доступность моделей
# раннеры: test-assignment/runner.py (планируется)
```
