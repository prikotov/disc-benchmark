# disc — тестирование копирования веб-приложения

Моделям дают только задание и **ссылку на источник** — тест DISC школы
менеджмента Stratoplan (https://stratoplan-school.com/disc/). Модель работает
агентом (pi, инструменты по умолчанию, доступ в сеть): сама изучает страницу
и код, сама собирает материалы и переносит функционал в копию —
одностраничное HTML-приложение, без бэкенда и без отправки результатов
на почту. Цель — измерить, насколько верно работает копия и насколько
качественно сделан перенос.

Качество переноса сравниваем с эталоном, снятым с оригинала заранее
(вопросы посимвольно, типы d/i/s/c, алгоритм, поток): машинные проверки
(структура, посимвольные данные, смоук с пересчётом баллов) + судейство
по 4 осям 0–4 (data / logic / ux / impl). Эталон модели не показывается.

Конвенции и процесс — **[AGENTS.md](AGENTS.md)** (главный документ workspace).
Полное описание методики тестирования — **[reports/METHOD.md](reports/METHOD.md)** (промпт, запуск pi, проверки, судья, агрегация).

## Структура

| Путь | Что лежит |
|---|---|
| `test-assignment/TASK.md` | задание, которое получает модель (только текст + ссылка) |
| `test-assignment/prompts/` | задание для прогона (версионируется; текущий v3 — агентный) |
| `test-assignment/reference/source/` | снимок оригинала (модели не выдаётся): `page.html`, `widget.html`, `disc_patched.js`, `result-page.html`, `manifest.json` |
| `test-assignment/reference/` | эталон для сравнения (модели не показывается): `original.md` + `questions.json` (24 вопроса с типами) |
| `test-assignment/rubrics/` | рубрика оценки (4 оси 0–4) и план машинных проверок |
| `team-assignment/` | второе задание: DISC-продукт с нуля (Symfony, LLM-интерпретация, почта, деплой на ai-aid.pro) строит LLM-команда — роли по Белбину, поведение по DISC, сабагенты pi |
| `models/<модель>/` | карточка `model.md` + прогоны `test-assignment/run-XX/` (`run.json`, след сессии `pi-session/`, `index.html`) |
| `team-runs/<состав>/` | командные прогоны `run-XX/` (след тимлида и сабагентов, workspace команды, прод-evidence) |
| `reports/` | кросс-модельные своды; `spend.csv` платных API (вне git) |

## Быстрый старт

```bash
cp .env.local.example .env.local   # вписать адрес сервера моделей
curl "$OLLAMA_BASE_URL/api/tags"   # проверить доступность моделей
# раннер агентных прогонов: test-assignment/runner.py (планируется)
```
