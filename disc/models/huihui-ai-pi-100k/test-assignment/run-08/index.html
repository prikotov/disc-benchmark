Тестирование DISC: определите свой стиль поведения

8 коротких шагов. В каждом — расставьте определения по степени близости вам: от наиболее похожего на вас до наименее похожего.

По итогам вы увидите свой DISC-профиль — уровни по четырём поведенческим измерениям: D (Доминирование), I (Влияние), S (Стабильность), C (Соответствие).

Ваш результат

Оценка каждого измерения рассчитывается по месту соответствующих определений в вашем ранжировании: определения, которые вы поставили на первое место, повышают соответствующий показатель, на последнее — понижают. Диапазон значений по каждому измерению: от −8 до +8. Обратите внимание: мы не даём расшифровку ваших индивидуальных результатов — этот инструмент помогает в самотестировании и в работе с командами и коллегами.
