Короткий тест: 8 шагов, по 3 карточки на каждом. Разместите качества в порядке от «наиболее похожего на меня» до «наименее похожего». По итогам вы получите баллы по четырём типам — D, I, S, C — и увидите свой поведенческий профиль.

Четыре типа поведенческого стиля

  • D · Dominant — доминантный
  • I · Influential — влиятельный
  • S · Steadfast — стабильный
  • C · Compliant — конформный

Как проходит тест

  1. На каждом шаге три карточки с четырьмя качествами.
  2. Перетащите качества: 1 — наиболее похожее на вас, 4 — наименее похожее.
  3. Навигация вверху: шаги «Первый» … «Восьмой», кнопки «Назад» / «Далее».
  4. На шаге «Восьмой» нажмите «Завершить тест» — увидите баллы сразу, без email.
