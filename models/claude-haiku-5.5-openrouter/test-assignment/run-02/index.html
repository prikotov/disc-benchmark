Тестирование DISC

Помните - чем честнее вы с тестом, тем точнее результаты!
Разместите блоки в порядке от наиболее похожего на вас до наименее похожего
Ваш DISC-профиль:
D:0, I:0, S:0, C:0

D — доминирование, I — влияние, S — стабильность, C — соответствие. Баллы: сумма по выбранным на первой позиции («наиболее») минус сумма по позиции «наименее» для каждого типа.

Мы не даём расшифровку индивидуальных результатов: тест — инструмент для самотестирования и для дальнейшей работы с командой.
