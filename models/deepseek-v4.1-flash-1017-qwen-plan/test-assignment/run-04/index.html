Тест завершён

Ваш DISC-профиль:

D: 0 I: 0 S: 0 C: 0

Баллы считаются так же, как в оригинале: выбранное «наиболее» даёт +1 типу, «наименее» — −1. Итоговая строка: D:0, I:0, S:0, C:0

Каждый шаг — три блока по четыре прилагательных. Балл типа — разница между тем, сколько раз его прилагательное оказалось для вас самым подходящим и сколько раз — самым неподходящим. Значения могут быть отрицательными.
