Ваши результаты DISC

Ниже представлены ваши баллы по четырем основным типам поведения.

D (Доминирование): Решительность, инициативность, ориентация на результат.

I (Влияние): Общительность, оптимизм, умение вдохновлять.

S (Стабильность): Надежность, терпение, умение слушать.

C (Соответствие): Точность, внимательность к деталям, системность.
