Короткий тест DISC

DISC — модель поведенческих стилей: Dominance (Доминирование), Influence (Влияние), Stability (Стабильность), Compliance (Соответствие). Пройдите тест и узнайте, какие стили проявляются у вас сильнее всего.

  • 8 коротких шагов — займёт несколько минут
  • На каждом шаге — просто расставьте слова по порядку
  • В конце получите свой профиль в формате D / I / S / C

Вы прошли тест!

Обратите внимание: это общая модель поведенческих стилей, а не индивидуальная расшифровка. Используйте эти данные для самоанализа и работы с командой.

D — Dominance (Доминирование)Напор, решительность, ориентация на результат
I — Influence (Влияние)Эмоциональность, общительность, оптимизм
S — Stability (Стабильность)Спокойствие, надёжность, ориентация на других
C — Compliance (Соответствие)Точность, системность, следование правилам
