# inkling-2-mini-pi-128k (ollama nserv)

Inkling 2 Mini — малая open-weights модель Thinking Machines Lab
(локальная, ollama nserv). Карточка-заготовка создана 2026-11-26 при
установке; в сестринском workspace карточки нет. Прогонов disc: 0.

## Характеристики

- **Теги на nserv**: run-тег `inkling-2-mini:pi-128k` (num_ctx 131072 +
  сэмплинг производителя, см. ниже); базовые `:26b-a5b` и
  `:26b-a5b-iq4_NL` — один дайджест весов `2b942cf7664624de` (IQ4_NL,
  18.3 ГБ). Базовые теги для прогонов не использовать.
- **Производитель**: Thinking Machines Lab; релиз 2026-11-20; Apache 2.0;
  мультимодальная (текст + изображения); model card:
  thinkingmachines.ai/model-card/inkling-2-mini/, веса на HuggingFace.
- **Архитектура** `inkling2_loop`: MoE 26.1B всего / **5.4B активных**
  (128 экспертов, 8 used, expert FF 1152), **looped layers** — блоки 6–18
  прокручиваются ×3 (≈36 эффективных слоёв из 24), SWA-гибрид (окно 1024,
  каждый 6-й слой полный), shortconv (l_cache 4), словарь 201 024.
  Вычислений на токен больше, чем говорит число активных параметров.
- **Контекст**: нативно 1 048 576. Наш тег — **131 072 (128k)**:
  проверено на 5090 32 ГБ — 28.7/29.8 ГБ в VRAM, ~1.1 ГБ offload,
  на скорость не влияет. 102400 тоже влезает (полностью в VRAM).
- **Capabilities**: completion, vision, tools, thinking.
- **Thinking**: градации `false / low / medium / high`. Нюанс
  производителя: минимальный уровень **не выключает reasoning полностью** —
  для серии наш «off» фактически «minimum» (фиксировать в run.json).
- **MTP**: нет (без `draft_num_predict`/nextn — положение как у bonsai-2).
- **Сэмплинг**: рекомендация производителя — `generation_config.json`
  на HF: `temperature 1.0, do_sample true`, без top_p/top_k/min_p
  обрезок. GGUF-метаданные (`general.sampling.*`): temp 1, top_k 50,
  top_p 1, min_p 0. Всё это **запечено в `pi-128k`** (ollama иначе
  подставляет свои рантайм-дефолты 0.8/40/0.9 — они НЕ рекомендованы).
- **Квантование**: IQ4_NL c imatrix (`inkling2-loop-calibration-v6.txt`);
  nvfp4-вариант — MLX-only (macOS), на Linux недоступен.

## Установка на nserv (2026-11-26)

- Требует **ollama ≥ 0.40.18** — сервер обновлён 0.40.7 → 0.40.18
  (инсталлятор пересоздал юнит; дроп-ины `OLLAMA_KV_CACHE_TYPE=q8_0`,
  flash-attention, host сохранены; бэкап бинарника
  `/usr/local/bin/ollama.bak-0.40.7`).
- Скорость: **63–93 tok/s** на RTX 5090 (разброс между запусками) —
  в 4–6 раз быстрее наших 27B dense; маленькое активное число параметров
  без спекуляций.
- Санити при установке: арифметика верна на всех уровнях thinking
  (думает по-английски даже на русском промпте), tool call корректный
  (`get_weather` → `{"city":"Moscow"}`).

## Предупреждения производителя (model card) — критично для прогонов

1. **Деструктивные действия без подтверждения**: может удалять/
   перезаписывать файлы и **неверно отчитываться о сделанном**. Для disc
   это главный риск контейнмента (у нас уже были выходы агента за
   workdir с другими моделями): проверка `git status` + посторонних
   файлов в методологии/эталоне после **каждого** прогона обязательна,
   evidence — в `run-XX/escape-evidence/`.
2. **Reasoning-петли**: застревает в длинных размышлениях и перепроверках
   без прогресса, особенно при отладке кода; производитель рекомендует
   лимиты выходных токенов и ходов агента. У pi лимит выхода стоит
   (32k) — следить за обрывами в `pi-run.log`; тайм-аут прогона
   обязателен.
3. **Языки кроме английского слабее** (в китайском наблюдались обрывочные
   фразы и смешение языков). Наши задания — на **русском**: систематический
   риск качества вывода, судьи учитывают как свойство модели.
4. **Фактическая точность**: увереннее ошибается, чем большие модели
   (factual recall — самая слабая сторона).
5. Поддержка looped-моделей в локальных рантаймах нова, скорость
   варьируется по рантаймам и железу — подтверждено нашим разбросом.

## Статус

- **Кандидат волны 2** `test-assignment/` (малые/«пол возможностей»;
  соседи по слоту — `qwen3-vl:30b-a3b` 3B активных, `gemma4-e2b` 4.6B).
- В командное задание (`team-assignment/`) пока **не ставить**: 5.4B
  активных — риск для ролей с глубоким reasoning (architect/backend/
  reviewer); решение после серии волны 2.
- Уровни серии: off / low / medium (high — отдельная проба, аналог xhigh,
  в стандарт не включать).
- Ещё один participant-нюанс: первый участник сетки с vision+tools+
  thinking одновременно (vision в текущих заданиях не задействован).
