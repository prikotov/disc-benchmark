# qwen4-max-preview (alibabacloud qwen-token-plan)

## Характеристики

- Модель: `qwen4-max-preview` — флагманская Qwen следующего поколения
  на подписке alibabacloud (Model Studio token plan); в pi-каталоге
  числится, custom id через `--provider qwen-token-plan-individual`
- Транспорт: `knowledge-map/runner_pi.py` (pi -p --no-session per
  клетка, `--mode json` отдаёт usage: input/output/cacheRead/reasoning)
- **Нюанс off (исправлено 2026-11-12)**: pi не передаёт alibabacloud
  `enable_thinking:false` — запрошенный off эскалируется в low;
  «off»-прогон от 2026-11-12 фактически был low и перенесён в run-02
  этой серии. Нативная шкала провайдера: off (enable_thinking:false) /
  low / medium / high (xhigh) — будущие прогоны off/medium пойдут
  через прямой транспорт runner_cloud.py

## quiz — анкета DISC (2026-11-17, ru + en, по 2 прогона на уровень)

Транспорт: прямой API alibabacloud (quiz/runner.py; enable_thinking=False
для off — честный off: reasoning=0, ~6 с, пилот подтвердил). Версия API:
`qwen4.0-max-preview`.

Документированная шкала (help.aliyun.com, qwen4-max-preview):
reasoning_effort = **low / medium / xhigh** (дефолт xhigh); off —
enable_thinking=false (проверено: 0 reasoning).

**Документированная лестница (по 2 прогона):**

| | off | low | medium | xhigh |
|---|---|---|---|---|
| ru | **17.0 (71%)** | 14.5 | 14.0 | 16.5 (69%) |
| en | **18.5 (80%)** | 15.5 | 14.5 | 15.5 (67%) |

**high (недокументированный уровень) — отдельная точка, не в лестнице:**
ru 15.0, en 15.0. Позиция в шкале неопределена: пробы reasoning-токенов
противоречивы (промпт А: 323 ≈ medium 302; промпт Б: 1034–1312, ближе к
xhigh-диапазону). Объединять с medium/xhigh не стал — см. выводы серии.

Флагман Qwen — середняк анкеты, лестница **обратная**: лучший результат
на off, любое рассуждение снижает балл (−3…−5); xhigh ближе всех к off
(16.5 на ru), но всё равно ниже. Язык: +9.6 п.п. на en. Похожий профиль
у карты знаний (98% — верх доски): общие знания велики, методология
курса — нет. Квота: 20 прогонов суммарно — `reports/spend.csv`.
Детали: `quiz/run-01…10`, `quiz-en/run-01…10`.
