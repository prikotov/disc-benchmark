## Наблюдения

- **Высокая вариативность на всех уровнях**: разброс 0–16 внутри одного
  уровня. Ни один режим не стабилен.
- **off — паралич**: run-03 не создал ни одного файла за 60 минут
  (совпадает с сестринским наблюдением «размышляет, не работает»), при
  этом run-01/02 написали решения (одно из них с логикой=0) — тип проблемы
  меняется от прогона к прогону.
- **Данные переносятся хорошо, когда решение написано**: 84/84 посимвольно
  и 96/96 типов в 7 из 8 решённых прогонов; run-04 (low) — 81/84 (промах
  по трём прилагательным).
- **Подсчёт — слабое место**: logic=0 (run-01) и logic=2 (run-07) —
  балл считает не по макс/мин позициям.
- **Цена высокая для 27B**: до 380k входных/197k выходных токенов на
  прогон (medium), медленно (до 60 мин).

## Сравнение с прогнозом (reports/FORECAST.md)

Прогноз B ставил bonsai **последним (7-е место)**, «дно» — и это
**подтвердилось**: единственная модель серии с полным параличом (0 файлов)
и единственная с logic=0. Рейтинг карты знаний (87.0, выше ornith-off и
почти на уровне ornith-on) **переоценил** bonsai для агентной задачи —
прямой аргумент для мета-вывода «карта знаний не переносится на агентную
задачу напрямую».
