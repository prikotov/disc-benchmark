## Наблюдения

- **Полный крах**: ни одно из 6 решений не переносит данные теста
  (0–2 прилагательных из 84); index.html создаётся во всех прогонах,
  кроме run-02 (1-секундный пустой выход).
- Файлы-пустышки: DOM 22–68 КБ может быть только каркасом без контента.
- Сестринский вывод («нижний край шкалы», clef 2.58 на собесе)
  **подтверждён и на нашей задаче**, с ещё более низким результатом.

## Вывод

- gemma4:e2b (4.6B) непригодна для задачи копирования веб-приложения:
  не способна ни перенести данные, ни построить работающий визард.
- Для мета-исследования — нижняя граница шкалы подтверждена независимо.
