24 вопроса (ru) / 23 вопроса (en) по методологии DISC/ 480 прогонов. Сформировано: 2026-11-20 03:58 UTC.
Примечание. (1) Межформатная — тонкость для LLM: в книге каждый вопрос дан с вариантами ответа. Decision-модели (clef) получают анкету как в книге — варианты видны (утверждения-пробы «правильный ответ — „X“, argmax): задача — выбор из видимых кандидатов. Генеративные LLM получают только вопросы, без вариантов: задача — воспроизведение (определить профиль самому) — условия строже. Баллы между форматами сравнивать с этой разницей; чистые сравнения — внутри формата. (2) Межъязыковая: ru — 24 вопроса, en — 23 (в английском оригинале нет вопроса про болезненную реакцию на критику), поэтому сравниваем проценты, а не сырые баллы.

Методика

  1. Материал. Анкета по методологии DISC — 24 вопроса (ru) / 23 (en); вопросы задаются без вариантов — модель называет профиль, сочетание или «нет однозначного ответа». Источник — блиц-тест из книги Томаса Эриксона: ru — «Кругом одни идиоты. Если вам так кажется, возможно, вам не кажется» (Эксмо, 2014); en — «Surrounded by Idiots» (английское издание, Macmillan/Ebury, 2019). Эталонные ответы сверены с разделом ответов книги (гл. 20) — снимки с правильными ответами: ru — quiz/reference/quiz-with-key.md · en — quiz-en/reference/quiz-with-key.md. Источник анкеты и эталонных ответов в промпте не упоминается.
  2. Прогон и запрос. Модель отвечает на все вопросы одним ответом (JSON «номер → ответ»), по 5 прогонов на модель×уровень (часть флагманов-облаков — по 2); сбойные прогоны не участвуют в метриках (колонка «сбои»).
    Запрос: системный промпт отсутствует — один user-месседж с полным текстом задания (интро + правила формата + вопросы, дословно из prompts/prompt.json). Параметры: stream false, num_ctx 65536, num_predict 32768, ручка мышления уровня (think / reasoning_effort / enable_thinking false — по API провайдера), seed не задаётся; остальное — дефолты модели. Для kimi (подписка Kimi coding) — тот же user-промпт без системного. Для clef — decision-протокол /v1/systemone (см. оговорку выше).

A quick little quiz: how well have you learned the DISC model?

DISC describes four behavioral profiles named after colors: Red, Yellow, Green and Blue. Test yourself: how well do you understand how people of different profiles act and behave?

Below are 23 questions. For each question, name the profile (color) that fits best; if the answer is a combination of profiles, name the combination; if there is no single answer, say so.

Answer strictly in JSON — an object mapping question numbers to your answers, no text outside the JSON:
{"1": "<your answer to question 1>", "2": "<your answer to question 2>", "3": "<your answer to question 3>", ..., "23": "<your answer to question 23>"}

  3. Уровни мышления. Каждый уровень, поддерживаемый моделью.
