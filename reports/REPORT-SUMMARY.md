# Копия DISC-теста как задача для LLM — текстовая сводка отчёта

Легковесная версия для машинного чтения (~12 КБ). Полный интерактивный отчёт (HTML ~0.7 МБ, скриншоты подгружаются отдельными файлами): <https://prikotov.pro/raw/disc-20261118/report.html>
Код, раннеры и сырые данные: <https://github.com/prikotov/disc-benchmark>

## Задача

15 моделей копируют открытый DISC-тест школы Stratoplan (<https://stratoplan-school.com/disc/>) в один самодостаточный HTML-файл: работа офлайн (`file://`), без бэкенда и внешних запросов; сбор email и отдельная страница результата из оригинала не переносятся — баллы показываются в самой копии. Модель получает только текст задания и ссылку на источник — страницу и код изучает сама. Промпт и набор инструментов (pi) у всех одинаковые.

## Объём

170 прогонов (уровни мышления от off до max), ~35 часов генерации, 1.04 млрд токенов (1.03 млрд входных с кэш-трафиком + 8.3 млн выходных).

## Как считается результат

1. Автопроверка: чекер сверяет данные анкеты с эталоном и проверяет рендер; драйвер проходит тест как пользователь, расставляя блоки перетаскиванием (24 вопроса, 8 шагов), и убеждается, что баллы D/I/S/C показались. Статус PASSED = все проверки вместе.
2. Судья яруса 1 (LLM): оси data / logic / ux / impl по 0–4, сумма 0–16 переводится в 0–100.
3. Vision-судья (LLM): три скриншота (старт/шаг/результат), оценка интерфейса 0–100.

## Выводы

- Облачные — верх таблицы: DeepSeek V4.1 Flash и Claude Haiku 5.5 прошли все прогоны, GLM-5.3-Flash — 14 из 15. MiMo-2.6-Flash — 3 из 8, единственная облачная с массовыми провалами.
- Локальные: лучший средний балл у базовой qwen3.8:27B (93, 18/20 PASSED), лучший PASSED у сборки huihui_ai/Qwen3.8-abliterated (20/20, средний 90). Дальше большой разрыв: orcarouter/Qwen3.8-27B-Uncensored 7/10, bonsai-2:27b 10/15, muse-glimmer 7/16, gemma4:31b 6/10, gemma4:26b 3/10, ornith-1.5:35b 1/10, ornith-1.5:9b и негатив-контроль gemma4:e2b — 0.
- Отказов от задачи нет ни в одном прогоне. Двух одинаковых по оформлению копий не нашлось.
- Корреляция с картой знаний PHP (10 пересекшихся моделей, ранговый коэффициент Спирмена со средним баллом судьи): «Всего ru» 0.97, колонка «Фронт.» 0.95 — значимо (порог при n=10 равен 0.65); «Глубина» 0.48 — не значимо. Карта знаний — рабочий первичный фильтр для подбора модели, финальный отбор — агентный прогон.
