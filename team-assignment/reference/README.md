# Провенанс данных (исправленный эталон)

| Файл | Что это |
|---|---|
| `questions.json` | **исправленный эталон** — выдаётся команде приложением к заданию |
| `questions.stratoplan.json` | дословный оригинал анкеты Stratoplan (снят 2026-11-14, копия `test-assignment/reference/questions.json`) — провенанс и база для сверки |
| `corrections.md` | полная таблица правок на утверждение владельцу: 16 позиций по аудиту книги, разрешение спорных по шкале самооценки, ребалансировка 6 вопросов, опечатка |

## Почему не дословно

Аудит по книге-первоисточнику (Т. Эриксон, «Surrounded by Idiots»;
REPORT.html §4) выявил **16 расхождений из 96** назначений «слово → тип»
у Stratoplan. Для задания на копию (`test-assignment/`) эталон остаётся
оригиналом «как есть» (семантика воспроизведения). Для нового продукта
заведомо кривые типы — плохой фундамент (интерпретация LLM строится
по баллам), поэтому здесь эталон исправлен:

- 16 позиций приведены к книге (14 уверенных + 3 спорных, разрешённых
  по **шкале самооценки русского издания** — `test-assignment/reference/self-assessment.json`,
  48 слов; метод и обоснования — `corrections.md` §2);
- наивная правка типов ломает инвариант «ровно один d/i/s/c в вопросе»
  в 6 вопросах — баланс восстановлен 7 заменами слов прилагательными
  из той же шкалы самооценки (`corrections.md` §3);
- опечатка «Экспресcивный» (латинская «c») исправлена.

Инварианты проверены: 24/24 вопроса сбалансированы, по 24 вхождения
каждого типа, сумма баллов = 0 на любой раскладке.

## Правила для судей и машинных проверок

- сверка данных продукта — против `questions.json` посимвольно;
  типы канонические, самовольные правки командой — дефект (ось SPEC);
- спорное решение «Дипломатичный → S» принято косвенно (единственный
  цвет, которому книга не противоречит) — владелец может пересмотреть;
  пересмотр = новая версия задания/эталона до старта серии;
- оставленные сознательно повторы с разными типами (Сдержанный c,s,s;
  Требовательный d,c) — не дефект эталона (аудитом не помечены).

## Контроль дрейфа

Оригинал снимка — `test-assignment/reference/source/` (манифест).
При изменении эталона в `test-assignment/reference/` синхронизировать
`questions.stratoplan.json` тем же PR; исправленный `questions.json`
пересобирается по `corrections.md` (правки типов + замены + опечатка).
