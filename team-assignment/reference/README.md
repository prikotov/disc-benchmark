# Провенанс данных

`questions.json` — дословная копия эталона
`test-assignment/reference/questions.json` (снят с оригинала
https://stratoplan-school.com/disc/ 2026-11-14, 24 вопроса, служебные
типы из `data-type` оригинала).

Отличие от одиночного задания: здесь данные **выдаются команде**
приложением к заданию (задание spec-driven: процесс описан, данные
приложены, внешний вид свободен). В одиночном задании модель добывает
данные сама — эталон ей не показывается.

Для судей и машинных проверок:

- сверка данных продукта — против этого файла (посимвольно);
- известные странности оригинала (латинская «c» в «Экспресcивный»,
  повторяющиеся прилагательные с разными типами, спорные назначения
  типов) — в этом задании воспроизводятся как есть; исправление опечаток
  допускается только с записью в журнале команды (чекер нормализует
  известные опечатки, как `known_quirk_normalized` в одиночной рубрике);
- спорные назначения типов (например «Энтузиаст» → c) — база Stratoplan,
  не исправляются командой; сверка с методикой книги — предмет отдельного
  задания (волна 4/5), не этого.

Контроль дрейфа: при изменении эталона в `test-assignment/reference/`
копия здесь обновляется тем же PR с пометкой в обоих README.
