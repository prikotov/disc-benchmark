# Роли команды, условие B: Белбин без DISC (контроль для A/B-серии)

Каталог — контрольное условие **B** эксперимента «управляет ли DISC-словарь
поведением агентов» (см. `../ORCHESTRATION.md`, «Серии и устойчивость»).
Карточки функционально идентичны условию A (`../roles/`): те же роли
Белбина, зоны ответственности, потоки, ограничения и форматы отчётов.
Отличия — **только** в `description` и вводном поведенческом абзаце:
тот же функциональный смысл поведенческих указаний, но без DISC-словаря
(ни типов d/i/s/c, ни названий профилей).

Интерпретация серии:
- поведение команд A и B значимо различается → DISC-словарь сам по себе
  влияет на поведение агентов;
- поведение совпадает → DISC в этой схеме — декорация к обычному
  role-prompting.

Методическая проверка эквивалентности (делает чекер/судья): дифф
A- и B-карточки должен показывать различия только в frontmatter
(`description`) и первом абзаце тела; все остальные разделы — посимвольно
идентичны.

## Распределение

| Роль | Файл | Роль Белбина | Зона ответственности |
|---|---|---|---|
| Тимлид | `teamlead.md` | Координатор (Coordinator) | оркестрация, продукт целиком |
| Аналитик-архитектор | `architect.md` | Мыслитель (Plant) | анализ задания, архитектура, контракты |
| Фронтендер / UI-UX | `frontend.md` | Исследователь ресурсов (Resource Investigator) | интерфейс, вёрстка, мобильность |
| Бэкенд-разработчик | `backend.md` | Реализатор (Implementer) | Symfony: данные, подсчёт, LLM, почта |
| Ревьювер бэкенда | `reviewer.md` | Оценщик (Monitor Evaluator) | ревью кода и решений бэкенда |
| Девопс | `devops.md` | Мотиватор (Shaper) | сборка, деплой, продакшен |
| Тестировщик | `tester.md` | Доводчик (Completer Finisher) | проверки: поток, баллы, почта, прод |

## Правила для всех ролей

- Инструменты — дефолтные pi, ничего не отключается.
- Общая среда — рабочая директория прогона: код продукта, `team/journal.md`
  (журнал решений), `team/mailbox/<роль>/` (письма между ролями).
- Каждая роль по завершении задачи пишет отчёт в журнал и возвращает
  тимлиду структурированный итог (что сделано / файлы / заметки).
- Секреты из окружения не печатать в логах и отчётах.
- Выход за пределы рабочей директории запрещён, кроме деплоя девопса
  на согласованный путь продакшена.
