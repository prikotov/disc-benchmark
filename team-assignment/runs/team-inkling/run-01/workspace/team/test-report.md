# Отчёт тестировщика — локальное приложение DISC

**Дата:** 2026-11-24 · Проверяющий: QA-агент · Сервер: `php -S` на http://127.0.0.1:8080/ (уже был запущен; не перезапускался)
**Сеть/LLM:** LLM API доступен (локальный ollama по `DISC_LLM_BASE_URL`). Почта недоступна ожидаемо (`DISC_SMTP_DSN` не задан) — это проверяется отдельно.

## Проверено

1. **Стартовая страница** `GET /` → **200**. Содержит заголовок, описание («24 вопроса, 8 шагов») и кнопку «Пройти тест».
2. **`GET /test` → 200.** Встроенный JSON `window.STEPS`: **8 шагов × 3 вопроса = 24 вопроса**. Все 24 вопроса идут по canonical `questions.json` посимвольно (проверено diff'ом: 0 несовпадений текстов, порядок item'ов не изменён). Типы прилагательных `d/i/s/c` в HTML/JSON **не видны**: ноль вхождений `"type":` в сыром HTML; у каждого item'а только `{"text": ...}`.
3. **`POST /test/finish` (валидный payload, email `qa-check@example.com`)** → **HTTP 200, `ok:true`**.
   - Профиль 1 (ротация 4-позиционных индексов): `{d:0, i:-6, s:2, c:4}` — сумма = **0**, каждая шкала в [-24;+24], совпадает с независимым пересчётом через Python (0 несовпадений).
   - Профиль 3 (полностью обратное ранжирование): `{d:-2, i:4, s:0, c:-2}` — сумма = 0, совпадает с пересчётом.
   - **Средние позиции переставлены** (swap позиций 1↔2 каждого вопроса) → баллы не изменились: `{d:0, i:-6, s:2, c:4}` в обоих вариантах. ✓
   - **Интерпретация от LLM**: непустая, на русском, 5–8 абзацев, индивидуальна — тексты профиля 1 и профиля 3 разные (len 2094 vs …, первые строки различаются).
   - `interpretation_unavailable: false`, `mail_sent: false`, `mail_reason: "Почта недоступна (DISC_SMTP_DSN не настроен)"` — честно помечено, поток не сломан. ✓
4. **Отказы → 400:**
   - Невалидный email → `400 {"ok":false,"error":"Некорректный email"}`. ✓
   - Неполные ответы (2 вопроса из 24) → `400 {"ok":false,"error":"Неполные ответы"}`. ✓
   - Дублирующийся индекс в списке (`[0,0,1,2]`) → `400`. ✓
5. **Статика**: `GET /css/app.css` → **200** (валидный CSS), `GET /js/test.js` → **200** (`node --check` OK).

## Дефекты

Не найдено. Все механики, проверенные этим прогоном, работают.

Замечания (не блокируют):
- `LlmInterpreter` не проверен на отказ LLM (недоступный endpoint) — ветка `return null` есть в коде и подхватывается в `interpretation_unavailable: true`, но сама ветка была не прогнана (server окружённые env'ы не менялись). Внешний UI шлёт честное сообщение при `null` (проверено по коду js, не по живому вызову).
- Отправка письма не проверена end-to-end: `DISC_SMTP_DSN` не задан, как ожидается; результат помечен честно.

## Что НЕ проверено в этом прогоне

- Браузерный поток end-to-end (тач-ранжирование, навигация, сохранение в localStorage, мобильная вёрстка) — этот прогон был направлен на бэкенд и статику.
- Письмо на реальный SMTP — недоступно по скоупу.
- Проверка продакшена — вне скоупа smoke-прогона (см. SCOPE.md).

## Вердикт

**Принято** (по критериям этого прогона): старт, /test (8 шагов, типы скрыты), подсчёт баллов (инварианты и пересчёт совпадают), LLM-интерпретация на русском, 400-кейсы, статика — всё подтверждено собственными инструментами.
